App name: Substitution

Description (short): A decentralized, encrypted social network built on Matrix. Your data, your server, your rules.
Beschreibung (kurz): Ein dezentrales, verschluesseltes soziales Netzwerk auf Basis von Matrix. Deine Daten, dein Server, deine Regeln.

Description (long):
Substitution is a social network that puts you in control. Built on the open Matrix protocol, it is not owned or operated by any single company. Instead of trusting a corporation with your data, you choose the server you connect to — or run your own.

Follow rooms created by artists, photographers and creators. Browse posts with images, videos and rich text. React, comment and engage with communities across the decentralized Matrix network.

Key features:
- Decentralized: Connect to any Matrix homeserver. No single point of control.
- End-to-end encryption: Rooms can be fully encrypted so only participants can read the content.
- Rich media posts: Creators can share images, videos and formatted text using a built-in editor.
- No tracking, no ads: Substitution contains no analytics, no crash reporting and no advertising SDKs.
- Open source: The full source code is publicly available on GitHub.
- Cross-platform: Also available on iOS, Web, Windows, Linux and macOS.

Substitution is an art project. It exists to demonstrate that an encrypted, decentralized social network is not just possible — it is practical.

Beschreibung (vollstaendig):
Substitution ist ein soziales Netzwerk, das dir die Kontrolle ueberlässt. Basierend auf dem offenen Matrix-Protokoll gehoert es keinem einzelnen Unternehmen. Anstatt einem Konzern deine Daten anzuvertrauen, wahlst du selbst den Server, mit dem du dich verbindest — oder betreibst deinen eigenen.

Folge Raeumen von Kuenstlern, Fotografen und anderen Kreativen. Entdecke Beitraege mit Bildern, Videos und formatiertem Text. Reagiere, kommentiere und vernetze dich mit Communities im dezentralen Matrix-Netzwerk.

Hauptmerkmale:
- Dezentral: Verbinde dich mit jedem Matrix-Homeserver. Kein einzelner Kontrollpunkt.
- Ende-zu-Ende-Verschluesselung: Raeume koennen vollstaendig verschluesselt werden, sodass nur Teilnehmer die Inhalte lesen koennen.
- Multimediale Beitraege: Ersteller koennen Bilder, Videos und formatierten Text mit einem integrierten Editor teilen.
- Kein Tracking, keine Werbung: Substitution enthaelt keine Analyse-Tools, kein Crash-Reporting und keine Werbe-SDKs.
- Open Source: Der vollstaendige Quellcode ist oeffentlich auf GitHub verfuegbar.
- Plattformuebergreifend: Auch verfuegbar fuer iOS, Web, Windows, Linux und macOS.

Substitution ist ein Kunstprojekt. Es zeigt, dass ein verschluesseltes, dezentrales soziales Netzwerk nicht nur moeglich, sondern auch praktisch nutzbar ist.
